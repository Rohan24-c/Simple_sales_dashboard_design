# 📊 Simple Sales Dashboard

This project is a basic interactive sales dashboard created using Power BI, based on the **Superstore Sales** dataset.

## 🔧 Tools Used
- Power BI
- (Optional: Python + Pandas for cleaning)

## 📁 Dataset
Superstore_Sales.csv  
(Columns: Order Date, Region, Category, Sales, Profit)

## 📌 Visuals Included
- 📈 Line Chart: Sales over Month-Year
- 📊 Bar Chart: Sales by Region
- 🍩 Donut Chart: Sales by Category
- 🎛 Region Filter Slicer

## 📄 Deliverables
- `Dashboard_Screenshot.png`: Power BI dashboard export
- `Insights.txt`: 5 Key insights from the dashboard

## ✅ Insights Summary
See `Insights.txt` for detailed observations on sales by region, category trends, and monthly performance.
